# Skill plates

One 16:9 JPG per skill, named after its id in `src/data/skills.ts`. The creator
shows them at the skill step; a missing file simply leaves the frame out.

```
one-handed.jpg      two-handed.jpg      archery.jpg
heavy-armor.jpg     light-armor.jpg     destruction.jpg
restoration.jpg     alteration.jpg      illusion.jpg
conjuration.jpg     sneak.jpg           lockpicking.jpg
speech.jpg
```

1024 × 576 or larger. Prompts and style rules: `docs/CREATOR-ART-BRIEF.md`.
