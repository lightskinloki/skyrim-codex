# Kit plates

One 16:9 JPG per starting kit, named after its id in `src/data/kits.ts`. A kit
plate is a still life of the gear — no people.

```
warrior.jpg      skirmisher.jpg      mage.jpg
spellsword.jpg   nightblade.jpg      ranger.jpg
```

1024 × 576 or larger. Prompts and style rules: `docs/CREATOR-ART-BRIEF.md`.
